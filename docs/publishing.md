# Публикация

Подготовлены ссылки на `https://github.com/malvere/gcom-home-assistant` и владелец `@malvere`. Репозиторий пока создаётся пользователем; локально Git не инициализировался и публикация не выполнялась.

1. Создайте публичный репозиторий `malvere/gcom-home-assistant` и отправьте в него содержимое этой папки как корень проекта.
2. Убедитесь, что проверки GitHub Actions **Tests**, **Hassfest** и **HACS** проходят. Сам HACS проверяет опубликованный репозиторий; локальные тесты не заменяют этот этап.
3. Создайте тег и GitHub Release `v0.1.0`. Версия в `custom_components/gcom/manifest.json` должна совпадать с номером выпуска.
4. Добавьте репозиторий в HACS как пользовательскую интеграцию и проверьте установку на отдельном экземпляре HA с собственным аккаунтом.

Не добавляйте в Git конфигурацию HA, токены, client secret, `.env`, `.storage` или данные аккаунта. Диагностические материалы исследования клиента находятся в отдельном проекте и для HACS не нужны.

Для нового выпуска обновите версию manifest, при необходимости встроенный клиент, выполните локальные тесты и выпустите новый тег. Встроенная иконка оригинальная и не является официальным логотипом 10G.com.

После проверки пользовательской установки можно отдельно запросить включение в основной каталог HACS по [инструкции публикации](https://www.hacs.dev/docs/publish/include/). До этого интеграция распространяется как пользовательский репозиторий.
